# KCD2 Dice — браузерная игра в кости на двоих онлайн

Веб-реализация игры в кости из Kingdom Come: Deliverance II. Два игрока, онлайн через лобби-коды или по локальной сети (Radmin VPN), игра в браузере без установки.

## Что нового в v2.10.0 — Игра с бляхой

- **Третий режим «Игра с бляхой»** — шулерские кости плюс одна бляха у каждого игрока: 4 активные (удвоение, воскрешение, превращение, обмен — кнопка «Применить» или B) и 4 пассивные (фора, «Разрез» плотника, «Виселица» палача, защита). Цели 6000 / 9000 / 12000, для долгих партий — 15000 / 18000
- **Внешний вид костей в классике** — в классическом режиме можно поставить пироги, зубы, кости художника и другие косметические кости; играют они честно
- **Кости соперника можно рассмотреть** — нажмите на его кость, чтобы узнать название, описание и шансы граней
- **Баланс** — каждая шулерская кость в наборе в одном экземпляре, косметические без ограничений; веса сверены с inara.cz
- **Удобнее на телефоне** — бляхи переехали в табло, индикатор хода больше не съедает пол-экрана
- Вкладка «Бляхи» в помощи (T); справочник — [`docs/BADGE_REFERENCE.md`](docs/BADGE_REFERENCE.md)

## Правила

6 кубиков. На своём ходу: бросаешь — выбираешь зачётные кости — решаешь продолжить (с риском зонка) или зафиксировать очки.

**Комбинации:**

| Комбинация | Очки |
|---|---|
| Одиночная «1» | 100 |
| Одиночная «5» | 50 |
| Три «1» | 1000 |
| Три N (N=2..6) | N × 100 |
| 4 одинаковых | ×2 от тройки |
| 5 одинаковых | ×4 от тройки |
| 6 одинаковых | ×8 от тройки |
| Стрит 1-5 | 500 |
| Стрит 2-6 | 750 |
| Стрит 1-6 | 1500 |

- **Зонк:** в броске нет ни одной зачётной — все очки хода сгорают, ход переходит.
- **Hot dice:** все 6 костей зачётные — обязательный переролл всех 6.
- **Стриты** засчитываются только в рамках одного броска.
- **Победа:** первый, у кого после фиксации очки >= цели (2000 / 3000 / 4000 — выбирается перед партией).

## Быстрый старт — онлайн

Игра развёрнута на **https://kcddice.ru** — установка не нужна.

1. Откройте **https://kcddice.ru** в браузере.
2. Нажмите **«Создать лобби»** — получите 5-символьный код и ссылку-приглашение.
3. Отправьте код или ссылку другу.
4. Друг открывает ссылку (или вводит код на главной) — оба попадают в лобби.
5. Нажмите **«Начать игру»**.

## Развёртывание на сервере (production)

Для запуска своей копии на VPS/VDS:

### Требования

- **Node.js 20+**
- Доменное имя с настроенным DNS (или IP)
- Обратный прокси (nginx / Cloudflare Tunnel) для HTTPS и WSS

### Установка

```bash
git clone https://github.com/Lelbry/Kcd_dice_web_lan.git
cd Kcd_dice_web_lan
npm install --production
```

### Запуск

```bash
# Прямой запуск
npm start

# С указанием порта
npm start -- --port 3000

# Через PM2 (рекомендуется для production)
npm install -g pm2
pm2 start server/index.js --name kcd2-dice -- --port 3000
pm2 save
pm2 startup
```

### Пример конфига nginx

```nginx
server {
    listen 443 ssl;
    server_name kcddice.ru;

    ssl_certificate     /path/to/cert.pem;
    ssl_certificate_key /path/to/key.pem;

    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

> **Важно:** WebSocket-соединения требуют заголовков `Upgrade` и `Connection "upgrade"` в проксе. Без них игра не подключится.

### Переменные окружения

| Переменная | Описание | По умолчанию |
|---|---|---|
| `PORT` | Порт сервера | `8080` |

## Развёртывание локально (Radmin VPN / LAN)

Для игры по локальной сети без внешнего сервера.

### Что нужно установить

**Node.js 20+** — скачайте LTS-версию с [nodejs.org](https://nodejs.org/en/download).

### Запуск

```bash
npm install
npm start
```

Откройте `http://localhost:8080` в браузере. Создайте лобби — покажется код. Второй игрок (в той же сети) открывает `http://<ваш-ip>:8080`, вводит код лобби и присоединяется.

### Игра через Radmin VPN

Если игроки в разных физических сетях — используйте [Radmin VPN](https://www.radmin-vpn.com/):

1. Оба установите Radmin VPN.
2. Хост создаёт сеть (**Network → Create network**), второй игрок присоединяется (**Network → Join network**).
3. Хост запускает `npm start` и сообщает свой Radmin-IP (формат `26.x.x.x`).
4. Второй игрок открывает `http://<radmin-ip-хоста>:8080`.
5. Оба создают/присоединяются к лобби по коду.

<details>
<summary>Если не подключается</summary>

- **Брандмауэр Windows:** при первом `npm start` разрешите `node.exe` доступ к сети (обе галки).
- **Не та сеть:** оба должны быть в одной Radmin-сети.
- **Проверка связи:** `ping <ip-хоста>` — должны идти ответы.
- **Порт занят:** `npm start -- --port 9090`.
</details>

## Игра против бота

Если играть некому — добавьте AI-противника прямо из лобби.

1. Создайте лобби и нажмите **«+ Добавить бота»** в свободном слоте.
2. Бот появится со случайным именем (KCD2-персонажи, гонщики F1, шахматисты).
3. Нажмите **«Начать игру»**.
4. После партии раскрывается **полное имя бота** и его стиль игры.

**Стили бота** — выбираются случайно:

| Настроение | Поведение |
|---|---|
| Осторожный | Банкует рано, минимум риска |
| Расчётливый | Сбалансированная стратегия |
| Дерзкий | Идёт на лишний бросок, охотится за hot dice |
| Безбашенный | Банкует только под победу |
| Хладнокровный | Чистая логика, без эмоций |
| Шальной | Непредсказуем — порог риска случайный |

| Помощь (правила) | `T` |

## Технологии

- **Сервер:** Node.js 20+, Express, `ws` (нативный WebSocket)
- **Клиент:** vanilla HTML / CSS / ES-модули, без бандлера и фреймворков
- **Тесты:** встроенный `node:test` (`npm test`) + Playwright для UI smoke (`npm run test:e2e`)
- **Авторитативный сервер:** клиент шлёт только намерения, сервер бросает кубики через `crypto.randomInt` и валидирует все ходы

## Структура

```
server/
  index.js          # Express static + WebSocket + lobby routing
  lobby.js          # LobbyManager: создание/поиск комнат по коду
  room.js           # GameRoom: FSM ходов, broadcast
  bot.js            # AI-противник с настроениями
  protocol.js       # типы сообщений + валидация
  engine/
    rules.js        # константы
    scoring.js      # scoreSelection(dice) → {score, valid, breakdown}
    validate.js     # canHold, canBank, checkWin, isFarkle
public/
  index.html        # lobby-select + lobby-waiting + игровой экран + модалки
  styles/           # main.css (layout) + dice.css (грани + tumble)
  js/
    main.js         # bootstrap, lobby flow, hotkeys
    glyphs.js       # SVG-символы для граней тематических костей
    badges.js       # UI блях: выбор, панель, кнопка, вкладка помощи
    infocard.js     # карточка «что это за кость / бляха»
    net.js          # WebSocket + reconnect backoff
    state.js        # snapshot store + selection
    ui.js           # рендер DOM по снапшоту
    engine/         # зеркало серверного движка (preview-скор)
tests/
  scoring.test.js   # 40+ кейсов
  validate.test.js
  weights.test.js   # распределение граней каждой кости
  balance.test.js   # симуляции партий loadout vs loadout
  badges.test.js    # движок блях + партии бот-vs-бот
  e2e/smoke.spec.js # Playwright: лобби → бот → pie loadout → победа
```
