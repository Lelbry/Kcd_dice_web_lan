## Режимы игры

### Классический
Все 6 костей — обычные. Выбора loadout нет.

Цели: **2000 / 3000 / 4000**

Средняя длительность партии (по симуляции 100 игр):
- 2000: ~7 ходов
- 3000: ~11 ходов
- 4000: ~15 ходов

### Карманные кости
Каждый игрок выбирает до 3 специальных костей в loadout. Взвешенные кости влияют на вероятности.

Цели: **4000 / 6000 / 8000**

Средняя длительность партии (по симуляции 100 игр, loadout Loaded+Painted+Lucky):
- 4000: ~10 ходов
- 6000: ~15 ходов
- 8000: ~20 ходов

## Как добавить новую кость

Добавить запись в `DICE_TYPES` в обоих файлах:
- `public/js/engine/dice-types.js`
- `server/engine/dice-types.js`

```js
{
  id: 'proposed_id',
  name: 'Русское название',
  description: 'Описание кости.',
  weights: [w1, w2, w3, w4, w5, w6],  // относительные веса граней 1-6
  color: '#RRGGBB',                    // уникальный насыщенный цвет
  special: true,                       // false для косметических
},
```

Оба файла должны быть идентичны. Цвета — яркие, различимые.
Макс. 3 специальных кости на игрока (`MAX_SPECIAL_DICE`).
