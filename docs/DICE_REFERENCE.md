# KCD2 Dice Reference

Полный справочник костей из Kingdom Come: Deliverance II.

Источники:
- Steam гайд: https://steamcommunity.com/sharedfiles/filedetails/?id=3426648052
- Steam гайд (альт.): https://steamcommunity.com/sharedfiles/filedetails/?id=3440227498
- Reddit (пост-патч таблица весов): https://www.reddit.com/r/kingdomcome/comments/1ijaac0/kcd2_dice_weight_table/

Format: `id | Name | weights [1,2,3,4,5,6] (%) | Notes`.
Реализованные помечены `[+]`.

## Implemented

Проценты посчитаны из фактических целых весов в `dice-types.js` (они
переведены из исходных процентов игры с сохранением пропорций, поэтому могут
отличаться от таблиц-источников на доли процента). Колонка Glyphs — грани,
на которых вместо точек рисуется SVG-символ из `public/js/glyphs.js`.

## How to Add a New Die

Add an entry to `DICE_TYPES` in both:
- `public/js/engine/dice-types.js`
- `server/engine/dice-types.js`

```js
{
  id: 'proposed_id',           // unique kebab-case ID
  name: 'Русское название',
  description: 'Описание кости.',
  weights: [w1, w2, w3, w4, w5, w6],  // relative weights for faces 1-6
  color: '#RRGGBB',           // unique saturated hex color
  special: true,              // false for cosmetic-only
  faceGlyphs: { 1: 'tooth' }, // optional: face -> glyph name from public/js/glyphs.js
},
```

Keep both files identical. Colors should be bold and distinct from existing dice.
Max 3 special dice per player loadout (`MAX_SPECIAL_DICE = 3`), не больше 2
одинаковых не-`normal` костей в одном loadout'е (`MAX_SAME_SPECIAL = 2`).

## Средняя длительность партии (симуляция)

По 100 прогонам `scripts/simulate.js` (бот-vs-бот, средние настроения):

**Классический** (все обычные кости):

- 2000 очков — ~7 ходов
- 3000 — ~11 ходов
- 4000 — ~15 ходов

**Карманные** (loadout Loaded + Painted + Lucky):

- 4000 — ~10 ходов
- 6000 — ~15 ходов
- 8000 — ~20 ходов
