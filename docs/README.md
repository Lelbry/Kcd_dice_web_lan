# Документация проекта

Здесь хранятся материалы по разработке, развёртыванию и развитию проекта. Сюда же складываются отчёты по итогам работ и значимые записи о развитии.

## Содержание

- [DEVELOPMENT.md](DEVELOPMENT.md) — заметки по разработке: архитектура, протокол, движок, тесты.
- [DEPLOYMENT.md](DEPLOYMENT.md) — развёртывание на сервере (production), nginx, Cloudflare, systemd.
- [DEPLOYMENT.docx](DEPLOYMENT.docx) — Word-версия документа по развёртыванию.
- [DICE_REFERENCE.md](DICE_REFERENCE.md) — справочник по правилам и комбинациям игры.

## Куда класть новое

- Записи о развитии (решения, фичи, рефакторинги) — рядом с существующими `.md` в этой папке.
- Отчёты (постмортемы, итоги работ, разборы инцидентов) — здесь же, с датой в имени: `YYYY-MM-DD-название.md`.
