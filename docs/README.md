# Документация проекта

Здесь хранятся материалы по разработке и развитию проекта. Сюда же складываются отчёты по итогам работ и значимые записи о развитии.

## Содержание

- [DEVELOPMENT.md](DEVELOPMENT.md) — архитектура, протокол, движок, тесты, инварианты.
- [DICE_REFERENCE.md](DICE_REFERENCE.md) — справочник по всем костям KCD2
  (веса, цвета, описания, чит-коды, средняя длительность партии).
- [DEPLOYMENT.md](DEPLOYMENT.md) — приватная шпаргалка по production-деплою на
  `kcddice.ru` (**в `.gitignore`, в публичный репо не уходит**).

Для быстрого контекста Claude в будущих сессиях — см. `CLAUDE.md` в корне.

## Куда класть новое

- Записи о развитии (решения, фичи, рефакторинги) — рядом с существующими `.md` в этой папке.
- Отчёты (постмортемы, итоги работ, разборы инцидентов) — здесь же, с датой в имени: `YYYY-MM-DD-название.md`.
